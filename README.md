Selamat datang di repositori website portofolio pribadi saya! Website ini dirancang dengan gaya desain modern menggunakan struktur **PHP Modular** untuk memudahkan pengelolaan komponen antarmuka pengguna (UI).

Halo! Saya **Mohammad Azhriel Muari Fullah**, mahasiswa Program Studi Sistem Informasi di Politeknik Negeri Subang. Saya memiliki ketertarikan kuat pada pengembangan web (Frontend & Backend) serta UI/UX Design. Saya senang membangun solusi digital yang fungsional, bersih, dan berdampak nyata.

## ✨ Fitur Utama

- **Fully Responsive:** Tampilan presisi dan rapi di semua ukuran layar (Mobile, Tablet, Desktop).
- **Modular PHP Structure:** Memisahkan Header, Navbar, Section, dan Footer ke dalam komponen `include` yang rapi.
- **Interactive UI:** Animasi transisi yang halus, efek _hover_, dan pop-up modal sertifikat yang interaktif.
- **Contact Form:** Terintegrasi dengan **Formspree** untuk menerima pesan dari pengunjung langsung ke email secara real-time.
- **Vercel Ready:** Dikonfigurasi secara khusus dengan `vercel.json` dan _lazy loading_ aset agar dapat berjalan cepat di server Vercel.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** PHP Native, MySQL
- **Design Tools:** Figma
- **Deployment:** Vercel (menggunakan `vercel-php@0.6.2`)

## 📂 Highlight Proyek

Beberapa proyek unggulan yang ditampilkan dalam portofolio ini:

1. **DelimaCare:** Sistem pelayanan layanan klinik terpadu (Laravel, MySQL, Tailwind, Alpine.js).
2. **Sistem Fotocopy:** Dashboard layanan administrasi fotocopy & print (PHP Native, MySQL, Chart.js).
3. **Synapse:** Inovasi hub web kolaboratif Berbasis AI dan IoT untuk UMKM Manufaktur (Figma UI/UX).
